# Changelog

All notable changes to **Omanges - Streaks Leaderboard** are documented here.

## [1.0.1]

### Added

- Initial public repository release.
- Automatic Twitch watch-streak tracking.
- Persistent JSON storage for viewer streak data.
- Current streak and highest streak tracking.
- `!streak` self lookup.
- Permission-controlled `!streak @username` lookup.
- `!streak leaderboard [page]` current-streak leaderboard.
- `!streak highest [page]` all-time highest-streak leaderboard.
- Pagination and configurable leaderboard page size.
- Customizable chat response and leaderboard formatting.
